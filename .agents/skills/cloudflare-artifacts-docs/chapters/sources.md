## Reconciliation of source conflicts

- **Binding content reads:** the older isomorphic-git introduction says the binding cannot read files. The current binding reference documents `readFile`, `readBlob`, `readTree`, `readCommit`, and `log`. Use the reference; Git remains needed for writing commits.
- **Repository handles:** the Sandbox SDK reuse snippet reads `.remote` and `.defaultBranch` directly from `get()`. The binding reference defines a disposable capability with `info()` for metadata. Chapter 6 adapts the example to current semantics.
- **Namespace creation:** older architecture prose says namespaces are not separately provisioned. Namespace and REST references document explicit creation as well as implicit creation on first repo. Create explicitly when setting jurisdiction.
- **Billing timing:** the pricing page updated 2026-10-28 says billing starts 2026-11-12. The older open-beta changelog says 2026-10-14. Chapter 10 gives precedence to the newer pricing reference, and requires live verification before quoting.
- **Git filtering:** ArtifactFS describes blobless startup, while the Git reference lists optional v1 `filter` as unsupported. Keep ArtifactFS as a documented specific workflow, flag compatibility for verification, and do not infer arbitrary partial-clone support.
- **Historical API snippets:** older changelog examples use earlier hosts/routes and creation result shapes. They are history, not current implementation examples.
- **Custom CI outputs:** source runners are isolated and branch from snapshots. Chapter 7 explicitly labels its build-output-lineage guidance as an inference and deploys from the build runner rather than assuming sibling outputs merge.
